# DNA-Sequence-Analyzer
Beginner Bioinformatics Project in Python

## Features
- DNA Validation
- DNA Length Calculation
- Base Counting (A, T, G, C)
- GC Content Calculation
- Reverse DNA Sequence
- Complement DNA Sequence
- Reverse Complement DNA
- RNA Transcription

## Technologies Used
- Python
